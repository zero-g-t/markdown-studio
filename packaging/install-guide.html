Markdown Studio {{VERSION}}

Chrome / Edge 扩展 · 离线运行 · 本地文件读写

安装说明

  1. 打开扩展管理页：在地址栏输入 chrome://extensions（Edge 用 edge://extensions）并回车。
  2. 打开页面右上角的 开发者模式 开关。
  3. 点击左上角的 加载已解压的扩展程序。
  4. 在弹出的选择框里，选中 markdown-studio-{{VERSION}} 文件夹，点「选择文件夹」。
  5. 列表里出现「Markdown Studio」即安装成功。点工具栏的拼图图标，把它「固定」到工具栏。
  6. 以后点击工具栏图标即可打开编辑器；也可以直接用它打开电脑上的 .md 文件。

使用注意

  • 只支持 Chrome / Edge / Brave 等 Chromium 内核浏览器，Firefox 不支持（缺少本地文件夹读写接口）。
  • 首次点「打开文件夹」时，浏览器会弹出授权提示，必须点允许，否则无法读取本地文件。
  • 不要删除、移动或重命名这个扩展文件夹：扩展直接从该文件夹加载，删掉或改名后立即失效。
  • 完全离线运行，不联网、不上传任何文件，全部数据只存在你自己电脑上。
  • 更新版本：把新版本的文件夹覆盖到原来安装的目录，回到扩展管理页点一次「重新加载」。
  • 卸载：扩展管理页点「移除」，然后删掉那个文件夹即可。
